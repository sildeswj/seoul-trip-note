## 気候同行カードとは？旅行者向け活用術

ソウル市が導入した「気候同行カード」は、公共交通機関の利用促進と気候変動対策を目的とした定期券です。ソウル市内の地下鉄とバスが一定期間乗り放題になるため、移動が多い旅行者にとっては非常に魅力的な選択肢となります。

### 気候同行カードの基本機能

気候同行カードは、ソウル市内の地下鉄と市内バスが、期間中何度でも利用できる交通パスです。旅行者が使いやすいのは、日数単位の**短期券**です。

**短期券の料金（執筆時点の目安）**

| 種類 | 料金 |
| :--- | :--- |
| 1日券 | 5,000ウォン |
| 2日券 | 8,000ウォン |
| 3日券 | 10,000ウォン |
| 5日券 | 15,000ウォン |
| 7日券 | 20,000ウォン |

カードは地下鉄駅のカスタマーセンターや一部のコンビニで購入し、駅の機械で短期券をチャージする流れが一般的です。チャージにはウォン現金が必要な場合が多いので、少し現金を用意しておくと安心です。住民向けの30日券は制度の見直しが進んでいるため、旅行者は短期券を前提に考えるのがおすすめです。

### 旅行者にとってのメリット

*   **交通費の節約**: ソウル市内の地下鉄やバスを頻繁に利用する場合、都度運賃を支払うよりも大幅に交通費を抑えられる可能性があります。特に、観光スポット間の移動が多い方にとっては、費用を気にせず気軽に公共交通機関を利用できるのが大きな魅力です。
*   **乗り換えのストレス軽減**: 乗り換えが多くても、追加料金を気にすることなく利用できるため、移動計画が立てやすくなります。
*   **ソウル市内観光に最適**: ソウル市内の主要な観光地は地下鉄やバスでアクセスできる場所が多いため、このカード一枚で効率的に観光を楽しめます。

### 気候同行カードの注意点

> **【注意点】気候同行カードの利用範囲と決済方法**
> *   **利用範囲の限定**: 対象は基本的に**ソウル市内の地下鉄とバス**です。ソウル市外で乗り降りする区間や、空港までの移動、新盆唐線（シンブンダンソン）など、使えない路線・区間があります。利用予定の路線が対象か、ソウル市の公式案内で確認してください。
> *   **現金が必要な場合が多い**: カードの購入や短期券のチャージには、ウォン現金が必要な場合が多いです。
> *   **決済機能なし**: 純粋な交通カードであり、店舗での決済には利用できません。別途、現金やクレジットカード、WOWPASSなどの決済手段が必要です。

## WOWPASSとは？キャッシュレス決済と交通カードの融合

![WOWPASSとはキャッシュレス決済と交通カードの融合](../../assets/blog/climate-card-vs-wowpass-comparison-2.jpg)

「WOWPASS」は、外国人旅行者向けに特化して開発されたプリペイドカードで、外貨両替、デビットカード、そしてTmoney交通カードの3つの機能を1枚にまとめた画期的なサービスです。韓国旅行中の決済と移動をこれ一枚で完結できるため、多くの渡韓女子に支持されています。

### WOWPASSの基本機能

*   **外貨両替**: 日本円などの外貨をWOWPASSのキオスクでウォンに両替し、カードにチャージできます。両替所を探す手間が省け、主要な場所で手軽に両替が可能です。
*   **デビットカード機能**: チャージしたウォン残高を、韓国国内のデビットカード加盟店（コンビニ、カフェ、レストラン、ショッピングモールなど）で利用できます。ほとんどの場所でキャッシュレス決済が可能です。
*   **Tmoney交通カード機能**: WOWPASSの裏面にはTmoneyカードの機能が搭載されています。別途チャージすることで、地下鉄、バス、タクシーなどの公共交通機関で利用できます。

### 旅行者にとってのメリット

*   **両替と決済の手間を軽減**: 空港や主要駅に設置されたWOWPASSキオスクで、日本円からウォンへの両替と同時にカードへのチャージが可能です。両替所を探す手間や、現金を持ち歩くリスクを減らせます。
*   **幅広い場所で利用可能**: Tmoney機能で交通機関、デビットカード機能で一般店舗と、これ一枚でほとんどの支払いをカバーできます。
*   **残高確認が簡単**: 専用アプリでチャージ残高や利用履歴をリアルタイムで確認できるため、使いすぎを防ぎ、予算管理に役立ちます。

### WOWPASSの注意点

> **【注意点】WOWPASSのチャージと手数料**
> *   **Tmoney機能は別途チャージが必要**: WOWPASSのデビットカード残高とTmoney残高は別々です。交通機関を利用するには、Tmoney機能に別途ウォンをチャージする必要があります。チャージは地下鉄駅の券売機やコンビニエンスストアなどで可能です。
> *   **手数料**: 初回登録料がかかります。両替・チャージ自体の手数料はかからないとされていますが、両替レートや手数料の最新条件は公式サイトで確認してください。Tmoney部分のチャージはウォン現金で行います。
> *   **残高の払い戻し**: 残ったウォン残高はキオスクで引き出せますが、手数料がかかる場合があります。

## よくある質問（FAQ）

### Q1: 気候同行カードは空港鉄道でも使えますか？

空港からソウル市内への移動には基本的に使えないと考えておくのが安全です（直通列車は専用の乗車券が必要です）。空港からの移動には、別途TmoneyカードやWOWPASSのTmoney機能、または切符を購入する必要があります。

### Q2: WOWPASSのTmoney機能と気候同行カードは併用できますか？

はい、併用は可能です。例えば、ソウル市内の地下鉄・バスを頻繁に利用する日は気候同行カードを使い、市外への移動や空港鉄道の利用時にはWOWPASSのTmoney機能を使う、といった使い分けができます。ただし、両方のカードを管理する必要があるため、どちらか一方に絞る方がシンプルな場合もあります。

### Q3: 短期旅行者（2〜3日）におすすめなのはどちらですか？

2〜3日の短期旅行で公共交通機関の利用頻度がそこまで高くない場合、WOWPASSの利便性が高いかもしれません。Tmoney機能に必要分だけチャージし、残りはデビットカードとして利用すれば、両替の手間も省けてスマートに旅行を楽しめます。1日の移動回数が多いなら、気候同行カードの短期券（1日5,000ウォンなど）も選択肢になります。

### Q4: 紛失した場合はどうなりますか？

気候同行カードの短期券は、紛失すると払い戻しや再発行が難しい場合があります。旅行者向けの対応は最新の公式情報を確認してください。
WOWPASSの場合、カード紛失時にはチャージ残高の払い戻しやカード利用停止の手続きができるとされています。ただし、カード発行手数料は戻らない場合が多く、Tmoney機能の残高は別途手続きが必要になることもあります。紛失に備え、カード番号などを控えておくことをおすすめします。
